# 生活助手工作区

面向四类日常用法的最小模板，可直接在 Cursor 里 `@` 对应文件后让 AI 帮忙整理。

| 目录 | 用途 | 建议模式 |
|------|------|----------|
| [`投资盯盘/`](投资盯盘/) | 观察清单、持仓笔记、复盘 | Ask 分析 → Agent 落笔 |
| [`孩子资料/`](孩子资料/) | 学科笔记、错题、学习计划 | Ask 讲解 → Agent 整理 |
| [`自己学习/`](自己学习/) | 主题、笔记、复习、输入输出 | Ask 弄懂 → Agent 落笔记 |
| [`写小说/`](写小说/) | 设定、大纲、章节稿 | Plan 大纲 → Agent / Inline Edit 改稿 |

## 怎么用

1. 打开对应目录里的说明（`README.md`）。
2. 把占位内容改成你的真实信息。
3. 对话时 `@` 相关文件，例如 `@投资盯盘/观察清单.md`。
4. 长期规矩已写在 [`.cursor/rules/`](.cursor/rules/)，Agent 会自动参考。

不需要的目录可以直接删掉。

## 桌面四个文件夹怎么进仓库

见 [`桌面导入说明.md`](桌面导入说明.md)。对应关系：

- `童童学习` → `孩子资料/童童学习/`
- `语言学习` → `自己学习/语言学习/`
- `赚钱` → `投资盯盘/赚钱/`
- `假死三年` → `写小说/假死三年/`

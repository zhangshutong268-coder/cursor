# 投资盯盘

用来做研究笔记与复盘，**不是**实时行情软件。行情仍用你平时的 App；这里只留「想清楚了没有」。

## 文件

| 文件 | 用途 |
|------|------|
| `观察清单.md` | 关注标的、触发条件、待验证问题 |
| `持仓笔记.md` | 持仓逻辑、成本与退出条件（可脱敏） |
| `复盘日志.md` | 按日/周记录决策与结果 |
| `模板-标的一页纸.md` | 新开一只标的时复制一份 |

## 和 Cursor 配合

- **Ask**：解读公告、对比逻辑、找论证漏洞（不改文件）
- **Agent**：把结论写进观察清单 / 复盘日志
- 输出尽量拆成：事实 / 假设 / 待验证

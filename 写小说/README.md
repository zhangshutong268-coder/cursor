# 写小说

建议结构：设定与大纲先稳，再按章扩写。改某一段时用 Inline Edit（选中后 `Cmd/Ctrl+K`）。

## 文件

| 文件 | 用途 |
|------|------|
| `设定.md` | 世界观、规则、时代背景 |
| `人物.md` | 人物卡、关系、禁止 OOC |
| `大纲.md` | 主线、分卷、章纲 |
| `文风.md` | 人称、节奏、禁忌 |
| `章节/01.md` | 正文（按序号追加） |

## 和 Cursor 配合

- **Ask / Plan**：聊情节分支、先出大纲
- **Agent**：扩写整章、统一设定
- **Inline Edit**：打磨一段对话或描写
- 新开章时新开对话，或明确「只改第 N 章」

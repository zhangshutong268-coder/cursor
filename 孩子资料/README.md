# 孩子资料

按学科整理笔记、错题与计划。先改 `档案.md` 里的年级等信息。

## 目录

| 路径 | 用途 |
|------|------|
| `档案.md` | 年级、作息、学习偏好 |
| `学习计划.md` | 周计划 / 假期计划 |
| `语文/` | 课文笔记、字词、阅读 |
| `数学/` | 知识点、错题本 |
| `英语/` | 单词、课文、练习 |
| `其他/` | 科学、兴趣等 |

## 和 Cursor 配合

- **Ask**：讲解题目、课文大意（不直接改文件）
- **Plan**：排一周或假期计划
- **Agent**：写入笔记、生成闪卡式复习清单
- 对家长：输出可附「家长检查清单」；对孩子：语气简洁、少说教

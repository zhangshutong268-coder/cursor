# 自己学习

和 `孩子资料/` 分开：这里只放**你自己**的学习目标、笔记与复习。投资相关深度研究仍放 `投资盯盘/`；这里适合课程、技能、阅读、方法论。

## 文件

| 路径 | 用途 |
|------|------|
| `学习档案.md` | 阶段目标、时间预算、偏好 |
| `主题清单.md` | 正在学 / 想学 / 已搁置 |
| `学习计划.md` | 周计划与完成勾选 |
| `笔记/` | 按主题建文件，见模板 |
| `复习卡片.md` | 易忘要点，定期回顾 |
| `输入输出.md` | 读了什么、写出了什么 |

## 和 Cursor 配合

- **Ask**：弄懂概念、对比方案（不改文件）
- **Plan**：排一个月学习路径或拆一门课
- **Agent**：整理笔记、生成复习题、写入计划
- 与投资重叠时：行情/标的决策进 `投资盯盘/`；通用知识（会计、宏观框架）可放这里
